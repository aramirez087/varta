# v0.2.0 — Turnkey Deployment & Safety Hardening

Varta v0.2.0 ships a complete deployment surface for `varta-watch` across five mainstream operator paths — `curl | sh` installer, multi-arch GHCR container, Helm 3.x chart, `cargo binstall`, and signed GitHub Release binaries. The observer itself gains three layered rate-limit defenses, fork-safety on the client, structurally bounded map WCET (replacing HashMap), and removal of shell-mode recovery. Breaking changes: `BeatOutcome::Dropped` now carries `DropReason`; default-on rate limits apply; recovery environment is isolated; `--recovery-cmd` is removed.

## Highlights

- **Turnkey install paths**: `curl | sh` installer (auto-versioned), multi-arch GHCR container with cosign keyless signing + SLSA L3 provenance, Helm chart to OCI registry, GitHub Release signed tarballs, `cargo binstall`.
- **Client fork-safety**: `Varta::beat()` detects fork via PID, auto-reconnects, and resets AEAD nonce state—no silent nonce reuse on `secure_udp`. Panic handler also fork-safe.
- **Rate limiting (default-on)**: Per-pid (`--max-beat-rate 100`), global token bucket (`--global-beat-rate 5000`), and SO_RCVBUF tuning (`--uds-rcvbuf-bytes 1M`). **Breaking**: use `--max-beat-rate 0 --global-beat-rate 0` to restore v0.1 unlimited behaviour.
- **Zero HashMap in production**: `BoundedIndex<K>` replaces HashMap in `Recovery.outstanding` and `PromExporter.ip_state`—tight WCET, no rehash latency, three new probe-exhaustion counters (all should stay at 0 under ≤50% load factor).
- **Shell-mode recovery removed**: `--recovery-cmd`, `--recovery-cmd-file`, and `/bin/sh` permanently excised. **Migrate**: use `--recovery-exec /path/to/program` with optional wrapper scripts.
- **Recovery environment isolation (default-on)**: Child processes inherit only `PATH=/usr/bin:/bin` plus explicit `--recovery-env KEY=VALUE` entries. **Breaking**: restore inheritance with `--recovery-inherit-env` (logs a stderr warning).
- **Fuzzing infrastructure**: nightly long-form corpus + OSS-Fuzz registration; twelve targets, 30 s per push/PR, 30 min nightly.
- **Supply-chain tightened**: Crypto deps (`chacha20poly1305`, `hkdf`, `sha2`, `zeroize`) pinned to exact patch versions; `cargo-deny` hard-deny on yanked/advisory/wildcard/unknown sources; `--locked` on all CI invocations.
- **Signal handler hardening (Linux)**: Direct `rt_sigaction(2)` syscall with custom `__NR_rt_sigreturn` trampoline instead of libc wrapper; assertion that kernel-preserved restorer pointer matches ours.

## Breaking changes

- `BeatOutcome::Dropped` now carries `DropReason` (reason: distinguish buffer pressure / observer-absent / peer-gone / storage-full). Migrate: `Dropped` → `Dropped(_)` or match specific variant.
- `--max-beat-rate` defaults to `100` (was unlimited). Use `--max-beat-rate 0` to disable.
- `--global-beat-rate` defaults to `5000` (new). Use `--global-beat-rate 0` to disable.
- `--uds-rcvbuf-bytes` defaults to `1048576` (new). Use `--uds-rcvbuf-bytes 0` to skip tuning.
- `--recovery-cmd`, `--recovery-cmd-file`, `--i-accept-shell-risk` removed. Use `--recovery-exec /path/to/program` instead.
- Recovery environment now isolated by default. Use `--recovery-inherit-env` to restore legacy behaviour (with stderr warning).
