==> Scrape /metrics from inside the cluster:

    TOKEN=$(kubectl -n {{ include "varta-watch.namespace" . }} get secret {{ include "varta-watch.tokenSecretName" . }} -o jsonpath='{.data.{{ include "varta-watch.tokenSecretKey" . }}}' | base64 -d)
    kubectl -n {{ include "varta-watch.namespace" . }} run curl-test --rm -it --image=curlimages/curl:8.10.1 --restart=Never -- \
        curl -sS -H "Authorization: Bearer $TOKEN" \
        http://{{ include "varta-watch.fullname" . }}.{{ include "varta-watch.namespace" . }}.svc:{{ .Values.service.port }}/metrics | head

==> Run the Helm test pod (asserts the bearer token + endpoint work):

    helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
