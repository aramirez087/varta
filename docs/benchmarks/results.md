# Varta Benchmark Results

This file is populated by `varta-bench` (Session 06 deliverable).

Benchmark numbers will appear here once the bench harness (`crates/varta-bench`)
is run against a release build. The root `README.md` links here so readers can
find measured latency and throughput data when available.

## Running the benchmarks

```sh
cargo bench -p varta-bench
```

Results are printed to stdout in a human-readable format. This file will be
updated with representative numbers from a reference machine before the v0.1.0
release.
