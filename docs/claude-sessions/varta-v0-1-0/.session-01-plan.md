## 3. Design decisions and rationale

1. **Virtual workspace (no root crate).** Keeps `Cargo.toml` minimal; every crate lives under `crates/`. Members declared explicitly so a stray top-level crate can't sneak in. `resolver = "2"` matches edition 2021.
2. **Skeleton lib.rs files include `pub use varta_vlp::*` re-exports immediately.** The session prompt explicitly says "re-exports point at vlp items that don't exist yet — that's fine, they'll resolve in step 6." Honored verbatim; the RED capture is scoped to `cargo test -p varta-vlp`, so sibling skeletons do not need to compile during RED. Workspace-wide gates run only after step 5 makes the imports resolve.
3. **`Frame` field order matches `repr(C)` natural alignment.** Layout: `magic[2] version[1] status[1] pid[4] timestamp[8] nonce[8] payload[8]` = 2+1+1+4+8+8+8 = 32 bytes with no padding because each 8-byte field is already 8-aligned after the 8-byte preamble. `align(8)` makes the struct's start address compatible with `u64` reads; `repr(C)` pins layout for ABI stability and FFI-style decoding.
4. **Encode/decode work over `&mut [u8; 32]` / `&[u8; 32]`.** Fixed-size arrays make zero-alloc trivially provable and sidestep slice-length runtime checks. The on-wire form is little-endian (the `to_le_bytes`/`from_le_bytes` family) — matches every supported target and is documented in `vlp-frame.md`.
5. **Decode validates magic, version, status — in that order.** Cheapest checks first; `BadStatus(u8)` carries the offending byte so debugging logs from `varta-watch` can surface it without re-decoding.
6. **`DecodeError` implements `Display` + `core::error::Error`.** `core::error::Error` (stable since 1.81) keeps the crate `no_std`-friendly without pulling in `std::error::Error`. The crate is `std`-using overall (UDS lives in `std`), but the protocol struct has no `std`-only impls — all impls use `core`.
7. **Status `try_from_u8` is a free function on the enum, not `TryFrom<u8>`.** Avoids requiring `core::convert::TryFrom` import discipline downstream and keeps the API surface minimal. `Status::try_from_u8(byte) -> Result<Status, DecodeError>` (returning `BadStatus(byte)` on failure) is a single hop — no extra error type plumbing.
8. **`MAGIC = [0x56, 0x41]` deliberately matches ASCII `"VA"`.** Easy to spot in hex dumps. Documented in `vlp-frame.md`.
9. **No `unsafe` in the VLP crate.** `from_le_bytes` / `to_le_bytes` cover every needed conversion. Decode does NOT use `core::mem::transmute`. This keeps the audit surface zero. Documented as a decision; if a future micro-opt requires it, the `// SAFETY:` comment rule applies.
10. **Compile-time layout assertions.** Two `const _: () = assert!(…)` lines at module scope: `size_of::<Frame>() == 32` and `align_of::<Frame>() == 8`. Test file ALSO asserts the runtime values, both for human readability and to harden against the off-chance of cfg drift.
11. **Bench placeholder uses empty `fn main() {}`.** Operator rule §Coding standards forbids `eprintln!` outside `varta-watch`'s binary; the placeholder needs to compile lint-clean and is replaced by Session 06.
12. **Tests live in `tests/frame.rs` (integration), not unit tests in `lib.rs`.** Integration tests exercise the public API the way Sessions 02+ will, and avoid testing private internals. This aligns with the contract's emphasis on public-API guarantees.
13. **Test fixtures avoid `tempfile`/`rand`/etc.** All test data is hand-built fixed-byte arrays; `Frame { … }` literals provide ground truth. Zero dev-deps in `varta-vlp` (consistent with operator rule even though dev-deps are technically permitted in test/bench crates only).
14. **`rust-toolchain.toml` pins `stable`, not a specific version.** Avoids drift while staying current. `profile = "minimal"` saves CI bandwidth; clippy + rustfmt explicitly added back via `components`.

## 4. Risks and mitigations

| Risk | Mitigation |
|---|---|
| Skeleton crates with `pub use varta_vlp::Frame` break workspace build before step 5. | Run RED gate as `cargo test -p varta-vlp` only (per prompt). Run workspace gates ONLY after step 5. Document this ordering explicitly in handoff. |
| `Frame` layout assertion fails on a target with unusual `u64` alignment. | `align(8)` is universally satisfied on tier-1 targets; `const _: () = assert!(...)` makes the failure a build-time error rather than a runtime one. |
| `core::error::Error` requires Rust ≥ 1.81. | `rust-toolchain.toml` pins `stable`; current stable is far past 1.81. If a downstream user sets `rust-version` lower, build errors are loud and immediate. |
| `clippy::print_stdout` lint in placeholder bins. | Bench placeholder is `fn main() {}`; watch placeholder uses `eprintln!` (allowed by rule). |
| Acceptance contract drifts from sibling prompts during downstream sessions. | Test names are mandated verbatim by Session 01 prompt and copied verbatim here. Behavior column is descriptive but the *name+file* pair is the contract. CI gate (Session 08) grep-validates presence. |
| Forgetting to omit `Frame`/`Status` from step-3 skeleton (which would invalidate RED). | Plan explicitly enumerates what each `lib.rs` contains at step 3 vs step 5. The step-3 vlp `lib.rs` contains crate-root attrs + module-level docstring ONLY. |
| `cargo fmt --all -- --check` fails because skeletons aren't formatted. | Format every file as it is written; sanity-check with `cargo fmt --all` before final gate run. |
| `tests/frame.rs` accidentally tests private items. | Tests import only from `varta_vlp::*` — no `crate::` references, no `mod` declarations to internal modules. |
| Workspace member listed but directory absent → `cargo metadata` fails. | Plan creates every member directory with at least `Cargo.toml` + `src/{lib.rs|main.rs}` before any cargo invocation. |
| `Cargo.toml` placement of `[workspace.package]` shared metadata accidentally inherited. | Use a *virtual* workspace (no `[package]` at root).
