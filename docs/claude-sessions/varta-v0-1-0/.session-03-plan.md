```rust
// crates/varta-watch/src/tracker.rs (sketch)
use varta_vlp::{Frame, Status};

pub struct Tracker {
    entries: [Slot; 64],
    len: usize,
}

#[derive(Clone, Copy, Debug)]
pub struct Slot {
    pub pid: u32,
    pub last_nonce: u64,
    pub last_ns: u64,
    pub status: Status,
    // private: tracks whether the observer has already emitted a stall event
    // for the current silence run; cleared on the next beat.
    stall_emitted: bool,
}

#[derive(Clone, Copy, Debug, Eq, PartialEq)]
pub enum Update {
    Inserted,
    Refreshed,
    OutOfOrder,
    CapacityExceeded,
}

impl Tracker {
    pub const fn new() -> Self;
    pub fn record(&mut self, frame: &Frame, now_ns: u64) -> Update;
    pub fn iter_stalled(&self, now_ns: u64, threshold_ns: u64)
        -> impl Iterator<Item = &Slot> + '_;
    pub fn len(&self) -> usize;
    pub fn is_empty(&self) -> bool; // clippy::len_without_is_empty
    // crate-private: observer flips this after surfacing Event::Stall for a pid
    pub(crate) fn mark_stall_emitted(&mut self, pid: u32);
}
```

```rust
use std::io;

use std::path::Path;

use crate::tracker::{Tracker, Update};

    sock: UnixDatagram,
    tracker: Tracker,
    threshold_ns: u64,
    start: Instant,

    Beat   { pid: u32, status: Status, payload: u64, nonce: u64 },

    Io(io::Error),
```

## 3. Design decisions (with rationale)

### A. Adding `varta-vlp` as a path dep — flagged tension

**Tension.** The operator rule says "Production crates ... MUST have a literal `[dependencies]` section that is empty. Only `core` and `std` are permitted" and the session quality gate restates "Verify `[dependencies]` still empty in `crates/varta-watch/Cargo.toml`." However, the same operator rules also state: "All inter-crate deps go through `path = "../<crate>"`. ... `varta-client` and `varta-watch` both depend on `varta-vlp` only." The contract tests for S03 (`Event::Decode(DecodeError::BadMagic)`) and the implementation requirement (use `Frame`, `Status`, `DecodeError`) cannot be satisfied without importing items from `varta-vlp`. Session 01's handoff anticipated this: *"Sessions 02/03 add both the path dep and the re-export together."*

**Resolution.** Add `varta-vlp = { path = "../varta-vlp" }` to `crates/varta-watch/Cargo.toml`. Treat the "empty `[dependencies]`" gate as "no registry / external deps" — the architecture mandate of "varta-watch depends on varta-vlp only" is the more specific rule and lines up with Session 01's recorded intent. Document this explicitly in the handoff Decisions block so Session 08's grep gate either accepts a path-dep-only manifest or flags the rule itself as needing tightening.

### B. `Slot` repr and packing

- **Default repr (Rust)**, not `#[repr(C)]`. `Slot` is internal to the observer; it is not on the wire and not subject to ABI guarantees. Default repr lets the compiler order fields for tightness.
- Stored fields: `pid: u32`, `last_nonce: u64`, `last_ns: u64`, `status: Status`, `stall_emitted: bool`. Predicted size with default repr: 24–32 bytes; well within the `<= 64*40 + 16 = 2576` budget the prompt asks us to assert.
- Compile-time bound: `const _: () = assert!(core::mem::size_of::<Tracker>() <= 64 * 40 + 16);`.

### C. Why `stall_emitted` lives on `Slot`, not next to `Tracker`

A stall must fire *once per silence run*: emit when silence first crosses the threshold, then suppress until a fresh beat resets the timer. The cleanest place to store the latch is the slot itself. We expose the latch only via a `pub(crate)` `mark_stall_emitted(pid)` so the public API stays minimal and the contract test for capacity bounding is unchanged.

### D. `iter_stalled` keeps the prompt's `&Slot` signature

The prompt specifies `iter_stalled(&self, now_ns, threshold_ns) -> impl Iterator<Item = &Slot>`. It is shared-borrow over all slots whose silence currently exceeds the threshold, regardless of emit state. The mutation needed for "emit once per run" is delegated to the separate `mark_stall_emitted` helper called by `Observer::poll`. This keeps the iterator pure and re-usable for future exporter code (Session 05) without a borrow-checker fight.

### E. Time accounting via `Instant::elapsed`

`now_ns = self.start.elapsed().as_nanos() as u64`. `Instant` is monotonic on every Varta-target platform. Casting `u128 → u64` is safe for any session length we care about (584 years at nanosecond precision); no saturation logic needed. `threshold_ns = duration.as_nanos().min(u64::MAX as u128) as u64` for the constructor — the saturating clamp is one expression and protects against absurd inputs without adding policy.

### F. `set_read_timeout(Some(100ms))`, not non-blocking

The observer is a single-threaded poll loop; the prompt explicitly says to use `set_read_timeout(Some(100ms))`. On `WouldBlock` / `TimedOut` we walk `iter_stalled` exactly once. 100ms cadence keeps stall latency bounded and CPU near zero (≪0.1% target for Session 06's bench). `set_nonblocking` is a `varta-client` rule; the observer can afford to park the kernel-side recv.

### G. `Observer::poll` event mapping

```text
recv result                                          → returned Event
─────────────────────────────────────────────────────────────────────
Ok(32)  & Frame::decode == Ok(frame) & record ==
   Inserted | Refreshed                              → Some(Event::Beat{..})
Ok(32)  & Frame::decode == Ok(frame) & record ==
   OutOfOrder | CapacityExceeded                     → None  (silently dropped)
Ok(32)  & Frame::decode == Err(decode_err)           → Some(Event::Decode(err))
Ok(n != 32)                                          → None  (truncated/oversized)
Err(WouldBlock|TimedOut)                             → first un-emitted stall
                                                        as Some(Event::Stall{..}),
                                                        else None
Err(_)                                               → Some(Event::Io(err))
```

Rationale: contract tests demand exactly `Event::Beat` per accepted frame, `Event::Decode(BadMagic)` for the `[0xFF; 32]` payload, and `Event::Stall` after silence. Dropping `OutOfOrder` / `CapacityExceeded` silently keeps the public API to the four documented variants and matches the operator-rule spirit of "drop and count" (the bench/exporter sessions can layer counters on top later).

### H. Default `Slot` initialization

`[Slot; 64]` is constructed once via `[Slot::EMPTY; 64]`. `Slot::EMPTY = Slot { pid: 0, last_nonce: 0, last_ns: 0, status: Status::Ok, stall_emitted: false }`. Slots beyond `len` are formally "unused" — `record` only scans `entries[..len]`. Pid 0 is reserved by Linux/macOS for the kernel scheduler so collisions with real agents are impossible; we never need to special-case "is this slot empty" outside of `len`.

### I. Re-using `varta-vlp` from tests vs. hand-rolling bytes

Tests import `varta_vlp::{Frame, MAGIC, VERSION, Status, DecodeError}` (already a transitive dep through `varta-watch`'s manifest, and Cargo's integration tests can `use` it directly). Hand-built bytes are reserved for the `0xFF; 32` decode-error case. This avoids re-implementing the byte map in the test file and keeps the contract pinned to the public API exactly as Session 02 will use it.

### J. No `unsafe`

The observer needs no `unsafe`. `UnixDatagram` is in `std::os::unix::net`; recv into a stack `[u8; 32]` is fully safe. Removing the stale socket file before bind uses `std::fs::remove_file` and ignores `NotFound`. Tracker is plain Rust. Net `unsafe`-block count for this session: zero.

### K. Bounded retry, not raw `sleep`

Both real-time tests (`...beat_per_received_frame`, `...stall_after_threshold_elapses`) drive `observer.poll()` in a `while Instant::now() < deadline` loop, sleeping `1ms` between empty polls. Deadline = `Duration::from_secs(2)` for the beat test (very generous; observer's own read timeout is 100ms) and `threshold + Duration::from_secs(1)` for the stall test. This satisfies the operator rule "use bounded retry loop, not raw sleep" — a single sleep before assertion would race against scheduler jitter and macOS's coarser timers.

### L. UDS path uniqueness in tests

Each test mints its path inside `std::env::temp_dir()` joined with `format!("varta-watch-s03-{}-{}-{}.sock", std::process::id(), thread_id, monotonic_counter)`. A static `AtomicU32` serves the counter so tests within the same process never collide. Cleanup runs through a small `OnDrop` helper that removes the socket file — `Observer::bind` already removes a stale file, but we don't want the test directory to accumulate orphans across runs.

## 4. Risks & mitigations

| Risk | Mitigation |
|---|---|
| `[dependencies]` "literal empty" rule conflicts with `varta-vlp` path-dep need (§3.A). | Add the path dep; document the conflict in handoff Decisions; flag for Session 08 grep-gate review. |
| `set_read_timeout` jitter on macOS is observable (kernel may return after >100ms). | Stall test deadline is `threshold + 1s`; we don't assert on latency, only on eventual delivery. |
| `Frame::decode` short-reads (`Ok(n != 32)`) treated as `None` could mask client bugs. | Acceptable for v0.1.0 — the contract only enumerates `BadMagic`. Document in handoff Open issues so Session 05 can decide whether to surface a `Truncated` variant. |
| `iter_stalled` requires shared borrow but stall-mark needs `&mut`. | Resolved by separating `iter_stalled` (read) from `mark_stall_emitted` (write) and calling them in distinct statements inside `poll`. |
| `Status::try_from_u8(frame.status)` could panic if called on an undecoded byte. | `Frame::decode` already validated the byte; we still call `try_from_u8` and `expect("frame validated")` so the invariant is named at the call site. |
| `Tracker` size budget might drift if a future field is added. | Compile-time `const _` assert pins it; any breaching change fails the build. |
| Test sockets pile up in `/tmp` if a test panics. | `Observer::bind` calls `remove_file` before bind; tests also use a per-run unique suffix (pid + counter). |
| Const-eval rejects `assert!` in older toolchains. | We're pinned to `stable` (Session 01); `assert!` in `const` context has been stable since 1.79. |
| Operator's "verify `[dependencies]` still empty" gate is a literal check. | If literal: it cannot pass and the rule contradicts the architecture; we record this and proceed. The handoff calls it out so the CI session (08) can codify the right interpretation. |
| `clippy::len_without_is_empty` triggers on `Tracker::len`. | Add `is_empty(&self) -> bool { self.len == 0 }` in the same impl block. |
